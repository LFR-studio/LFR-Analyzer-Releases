# LFR Analyzer

### Professional Audio Analysis Software by LFR Audio

**Free • Offline • Windows • Beta**

LFR Analyzer is a free desktop application designed for musicians, vocalists, sound engineers, music producers, and anyone passionate about creating music.

Our goal is to make professional audio analysis accessible to everyone — even without advanced knowledge of music theory.

---

## 🎵 Features

### 🎹 Key Detection
- Detect the musical key of audio recordings.
- Analyze songs, instrumentals, and musical arrangements.
- Help musicians better understand the harmonic structure of their music.

### 🥁 BPM Detection
- Automatically estimate the tempo of audio files.
- Assist with music production, recording, and arrangement analysis.

### 🎤 Vocal Inspector — Beta
- Visualize vocal pitch and melodic movement.
- Inspect vocal notes along a timeline.
- Explore potential intonation issues.
- Develop analysis of vocal performances in relation to instrumental harmony.

### 🎼 Harmony Analysis — In Development
- Analyze harmonic structures.
- Explore chord progressions and key changes.
- Improve the understanding of relationships between melody and accompaniment.

### 🔄 Application Updates
- Check for new versions through GitHub Releases.
- Follow the development of LFR Analyzer.
- Access beta updates and release notes.
